# Assets

| Path | What it holds |
|---|---|
| `logo/` | The logo files the engine and slides use, renamed by colourway: `wcn-horizontal-lime-white.png`, `wcn-mark-lime.png` and so on |
| `brand/png/`, `brand/jpg/`, `brand/svg/`, `brand/pdf/` | Every WCN brand file exactly as supplied on 20 Nov 2026, original names. `brand/svg/WCN SVG/` is the second SVG set |
| `references/` | What we are aiming at: the Nigerian campaign poster moodboards, two Ignovations slides for style, WCN's Instagram and X profiles (handles, voice), the whyvote.ng candidate screenshot, and the original content plan spreadsheet |

Brand colours, from the logo files: lime `#D1DD25`, forest `#0D421F`.
Brand font: Sora (in `../fonts/`).

Photos for posts do not go here. They go in `../images/` (and
`../images/candidates/` for cut-out portraits), so the render scripts find them.
